# V8 compatibility

V8 uses V5 execution semantics with eight-byte packed routine and string
addresses and eight-byte file-length units. The initial PC is still a byte
address; abbreviations still use two-byte word addresses. The V6/V7 routine
and string offset fields do not apply. See Standard 1.1
[§1, including its closing remarks](https://inform-fiction.org/zmachine/standards/z1point1/sect01.html).

The first milestone reaches the opening input request in all six retained V8
stories: Afflicted, Anchorhead, Lost Pig, Party Foul, Snack Time and Yomomma.
Independent synthetic tests execute routines and strings above 256 KiB and
restore high-PC checkpoints. V8 shares the V5 text, object and display formats.
This is text-interpreter compatibility, not a claim of complete Standard 1.1
conformance or V6 graphics support.

Linux comparisons use documented public calls to an installed Jericho
executable through its Python API. Reference implementation source is not
consulted. Portable tests read `<rom>_vectors.zip` directly with `zipfile` and
verify member and ROM hashes. Archives contain commands, scalar measurements
and hashes, never story text, memory dumps or ROM bytes. Regenerate them with:

```sh
uv run --group reference python -m tests.scripts.generate_zork1_vectors --only v8
```

The public reference uses a 128-column, 232-row header. Comparisons pass those
dimensions explicitly; Fernz's default remains 80 by 25. Opening transcripts
include both windows. Comparison helpers account for the reference's first
character and prompt clipping without changing Fernz's output stream. Snack
Time's literal `>` is preserved separately from its command prompt.

Fernz exposes each real input boundary. The test adapter advances Anchorhead's
three title-screen key requests, Snack Time's one key request, and Party Foul's
first key request and `no` tutorial answer to match public reference reset.
Party Foul then remains at a second character request. These startup actions
belong to the comparison fixture, not the interpreter.

The next milestones add action and persistence coverage, followed by complete
winning routes for Lost Pig and Snack Time and their story query profiles.
V8 Quetzal persistence and story-specific score/player/outcome queries remain
outside this first milestone. Generic object inspection and host checkpoints
are available already. Comprehensive V8 checks run in their own Linux and
portable jobs; synthetic coverage runs in quick PR checks.
